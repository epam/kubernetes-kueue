# config/components/

Reusable Kustomize components. Each sub-directory is a composable unit that can be included in overlay `kustomization.yaml` files.

## Components

| Component | Purpose |
|---|---|
| `crd/` | CRD manifests (generated by `controller-gen`) + patches to inject webhook CA bundles |
| `manager/` | Controller manager Deployment, ServiceAccount, ConfigMap (`controller_manager_config.yaml`) |
| `rbac/` | All RBAC resources: manager roles, leader election roles, secrets roles, metrics roles, batch aggregate roles |
| `webhook/` | Webhook service + generated `ValidatingWebhookConfiguration` / `MutatingWebhookConfiguration` manifests |
| `certmanager/` | cert-manager Certificate + Issuer for webhook TLS, metrics TLS, and visibility API TLS |
| `internalcert/` | Self-signed TLS Secret (used without cert-manager) |
| `visibility/` | APIService objects for the aggregated Visibility API (v1beta1 + v1beta2) |
| `visibility-apf/` | FlowSchema + PriorityLevelConfiguration for the Visibility API's API Priority and Fairness bucket |
| `prometheus/` | ServiceMonitor for Prometheus |
| `kueueviz/` | KueueViz frontend and backend Deployments, Services, Ingresses, ClusterRole |

## Usage

Components are included via `kustomization.yaml`:

```yaml
components:
  - ../components/certmanager
  - ../components/visibility
```
